## Embedding model
Взял по итогу [эту](https://huggingface.co/jinaai/jina-embeddings-v3), по идее просто хорошая модель эмбеддингов с поддержкой русского языка.

Для чанков текста переводит в эмбеддинги и добавляет в бд

Для запроса возвращает его эмбеддинг

#### NOTE:
 - Я делал чисто для работы на `cpu`, под инференс модели с `gpu` возможно нужно что-то дописать(помимо изменения в `requirements.txt`)

## Re-rank model
Использована [эта модель](https://huggingface.co/cross-encoder/ms-marco-MiniLM-L12-v2) с оберткой `FastAPI`.

Переранжирует отрывки текста, соотнося с запросом пользователя
